**Mar 2026** &nbsp;|&nbsp; _React, Vite, Node.js, Anthropic SDK, Yahoo Finance, Finnhub_

- Built a mobile-first stock discovery app with swipe mechanics for the AI@Princeton × Trade[XYZ] Hackathon: flippable cards show live AI analysis, real-time news, and interactive price charts.
- Integrated Claude Haiku and Sonnet via the Anthropic SDK for per-stock hooks and a holistic portfolio analysis with a Risk Radar dashboard.
- Physics-based swipe animations with Framer Motion, streaks and badges, a friends feed, and a vertical discovery feed.
- Real-time data layer pulling from Yahoo Finance, Finnhub, and the YouTube Data API through an Express/Node.js backend.
