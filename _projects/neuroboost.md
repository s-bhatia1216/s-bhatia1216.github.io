- Built a proof-of-concept cognitive monitor using galvanic skin response and heart rate variability as proxies for cognitive load and fatigue.
- Trained a hybrid CNN-RNN in TensorFlow/Keras to classify cognitive state (baseline, load, fatigue) from multivariate biosensor time series, with a live dashboard streaming readings and predictions.
